Cloud & Serverless: AWS Lambda, S3, CloudFront

Database & Auth: AWS RDS, DynamoDB, AWS Cognito

Languages used; Node.js/JavaScript, HTML5, CSS3

Summary of Technologies used: 

1. Engineered a scalable serverless architecture on AWS using Lambda for backend execution without server overhead.

2. Implemented a hybrid database approach using RDS for structured booking data and DynamoDB for flexible NoSQL data management.

3. Secured user onboardings via AWS Cognito identity workflows

4. Accelerated global website load times using S3 static hosting paired with CloudFront CDN distribution.
